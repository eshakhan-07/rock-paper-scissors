# Rock Paper Scissors

This is a simple Rock Paper Scissors game I made using Python.

The user enters Rock, Paper, or Scissor, and the computer randomly chooses one. The program then checks both choices and shows who won.

## How it works

- Enter your choice: Rock, Paper, or Scissor
- The computer randomly selects its choice
- The program compares both choices
- The result is displayed

## Technologies Used

- Python
- Random module

## How to Run

1. Download or clone this repository.
2. Open `rock-paper-scissors.py` in VS Code.
3. Run the Python file.
4. Enter your choice when asked.
